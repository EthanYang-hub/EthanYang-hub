# Order & Waybill Core Services

## Company

SF Technology

## Role

Java Backend Engineer

## Period

2016 - 2022

## Project Summary

Worked on large-scale logistics backend services responsible for order aggregation, routing-related data enrichment, and downstream waybill event distribution across internal systems.

## Business Context

The platform received orders from multiple upstream channels, including app-based orders, QR-code orders, and large customer batch orders. These orders had to be normalized into a unified internal structure, enriched with routing and location information, and then delivered to downstream systems for pickup, processing, and shipment lifecycle management.

## Scale

- Around 30 million orders processed per day
- Around 120 million downstream waybill-related events distributed per day

## My Responsibilities

- Participated in requirement analysis and backend design
- Developed core backend logic for order and waybill processing
- Worked on service integration between upstream and downstream systems
- Supported optimization and ongoing iteration of internal workflows
- Contributed to reliability improvements for high-volume processing scenarios

## Tech Stack

Java, Spring, Hibernate, Kafka, Redis, MySQL, Mycat, Hystrix, Saturn

## Challenges

The main challenge was supporting very high throughput while maintaining consistency across multiple connected systems. Order data came from different channels and had to be transformed into a unified format before routing and downstream distribution. The platform also needed to remain stable under heavy daily load.

## What I Did

I worked on backend service development for core processing flows, including order standardization, service coordination, and downstream event handling. I also participated in integration-related development and helped improve maintainability and operational stability in a large-scale production environment.

## Outcome

The system supported large daily transaction volume as part of a core logistics platform and helped ensure reliable order processing and downstream waybill distribution across business-critical internal services.
